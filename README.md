# Signal Live Project

Create a premium, modern, highly interactive and fully responsive landing page for AICON’26, using the attached AICON’26 logo as the primary branding reference.

The website is for a major student technology/innovation event and will be evaluated as a design and development task. It should feel professionally designed, memorable, modern and intentional, rather than like a generic AI-generated conference template.

CORE CREATIVE CONCEPT

Build the entire visual identity around:

“THE SIGNAL IS LIVE.”

The AICON logo contains a distinctive diagonal yellow line. Turn this diagonal line into a recurring visual motif throughout the website.

The line represents a signal connecting people, ideas, technology and creativity.

Use it subtly across section dividers, timeline elements, hover states, backgrounds and transitions so that the website has a consistent visual language.

Do NOT overuse it or make the site visually busy.

VISUAL STYLE

Create a combination of:

modern technology conference

premium creative studio

editorial/magazine design

university innovation event

The design should be minimal but visually striking.

Prioritize:

oversized typography

strong whitespace

bold visual hierarchy

asymmetric layouts

clean grids

sharp geometric elements

subtle motion

strong contrast

elegant micro-interactions

Avoid:

generic SaaS layouts

excessive rounded cards

excessive glassmorphism

excessive gradients

excessive shadows

stock-photo-heavy designs

unnecessary decorative elements

excessive animations

The website should feel like a real event campaign designed by a professional creative/web team.

BRAND COLORS

Extract the visual direction from the supplied AICON logo and primarily use:

AICON Blue: #1532B1

Signal Yellow: #FCDC58

Deep Red: #7D0202

Bone: #FDF8E9

Ink: #14161A

Use Bone and Ink as the main backgrounds, Blue as the primary brand color, and Yellow/Red as controlled accents.

Do not use all colors equally.

The overall palette should remain sophisticated and minimal.

TYPOGRAPHY

Use a modern geometric/editorial sans-serif typeface.

Use a bold display font such as Space Grotesk, Sora, or a similar modern font for large headings and a clean sans-serif such as Inter for body text.

Use very large typography for key statements.

For example:

THE SIGNAL
IS LIVE.

The typography should be one of the main visual elements of the design.

NAVIGATION

Create a sticky navigation bar.

Left:

AICON’26 logo

Right:

About

Events

Schedule

FAQ

Register

The navbar should start transparent/overlaying the hero and transition into a solid or slightly translucent background when scrolling.

Use smooth scrolling between sections.

On mobile, use a polished hamburger navigation.

The navigation should remain simple and uncluttered.

HERO SECTION

Create a dramatic full-screen hero section.

Main content:

Small label:

AICON’26 / SIGNAL DETECTED

Large headline:

THE SIGNAL
IS LIVE.

Supporting headline:

CONNECT. CREATE. CONVERGE.

Short supporting copy:

AICON’26 brings together technology, creativity, innovation and community in one immersive experience.

Primary CTA:

REGISTER NOW →

Secondary CTA:

EXPLORE AICON ↓

Use the supplied AICON logo prominently but elegantly.

Use the diagonal yellow signal line as a subtle animated element in the hero.

Possible visual treatment:

diagonal yellow line slowly animates/draws

subtle movement on background elements

small status indicator such as ● SIGNAL ACTIVE

subtle grain or texture

Do not create a long loading screen. The hero should load quickly.

The first viewport should immediately communicate:
AICON’26 + technology + creativity + energy.

ABOUT SECTION

Create an editorial-style About section.

Small label:

01 / ABOUT AICON

Large statement:

A PLACE FOR PEOPLE
WITH IDEAS.

Explain AICON as a platform bringing students, technology, creativity, innovation and community together.

Keep the copy concise.

Use an asymmetric layout rather than a conventional centered paragraph.

Include four supporting concepts:

TECHNOLOGY
Explore and build.

CREATIVITY
Turn ideas into experiences.

COMMUNITY
Meet people and collaborate.

INNOVATION
Challenge what is possible.

Use the diagonal signal motif as a visual separator.

EVENTS SECTION

Create an interactive events section.

Heading:

FIND YOUR FREQUENCY.

Subheading:

Explore the different ways to experience AICON’26.

Create four major interactive event cards:

01 — TECH

Build, experiment and explore technology.

02 — CREATIVE

Design, create and express ideas.

03 — COMPETE

Challenge yourself and solve problems.

04 — CONNECT

Meet people, collaborate and exchange ideas.

Cards should have polished hover interactions.

On hover:

card slightly expands or shifts

yellow signal accent appears

arrow animates

background/image treatment changes subtly

text remains readable

Do not make the cards overly rounded.

On mobile, make them easy to scroll/read vertically.

Hovering over each option should change its visual treatment.

This should feel like a personality/identity section rather than a normal feature grid.

Use smooth accordion animations.

Heading:

Primary button:

Use a strong combination of AICON Blue, Bone and Signal Yellow.

The registration button should have a polished hover interaction.

MICRO-INTERACTIONS

Add subtle premium interactions throughout the website:

smooth scrolling

scroll reveal animations

text fade/slide animations

button hover animations

arrow movement

event-card hover effects

FAQ accordion transitions

navbar transition on scroll

subtle diagonal signal-line animation

subtle cursor interaction on desktop if it does not hurt performance

Do NOT use excessive particle effects or distracting animations.

Animations should make the website feel polished, not slow.

Respect reduced-motion preferences where possible.

RESPONSIVE DESIGN

The website must be fully responsive.

Test carefully for:

desktop

laptop

tablet

mobile

On mobile:

typography must scale correctly

hero must remain visually powerful

navigation becomes a clean hamburger menu

cards stack naturally

timeline becomes vertical

animations remain subtle

buttons remain easily tappable

no horizontal overflow

no elements should overlap or become unreadable

Mobile quality is extremely important.

TECHNICAL REQUIREMENTS

Use:

React

Tailwind CSS

reusable components

modern semantic HTML

Lucide icons or another clean icon library

Framer Motion or lightweight CSS animations where appropriate

Organize the page into reusable components such as:

Navbar
Hero
About
Events
Experience
Schedule
FAQ
RegistrationCTA
Footer

Keep the code clean and maintainable.

Do not hardcode repeated UI unnecessarily.

Ensure:

no console errors

no broken links

no broken images

accessible buttons

keyboard-friendly interactions

good color contrast

responsive layout

smooth performance

Do not use fake statistics or claim official event details that have not been provided.

Use the supplied AICON’26 logo as the primary branding asset.

FINAL DESIGN GOAL

The final website should communicate:

AICON’26 is an energetic, modern, technology-driven event where people, ideas and creativity connect.

It should feel like a real branded event campaign, not a standard university landing page.

The design should be simple enough to feel professional, but distinctive enough that someone reviewing dozens of submissions immediately remembers it.

Prioritize visual polish, typography, spacing, branding consistency, responsive behavior and meaningful interaction over adding unnecessary features.
